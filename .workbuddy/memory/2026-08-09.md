## 项目通读（pmproject 项目管理系统）

首次全面了解代码库，未做任何修改。核心结论：

**项目定位**：仪控部内部「任务/项目管理 + 数据大屏」系统，Next.js 16 App Router + React 19 + TS + shadcn/ui + Tailwind 4，数据库为达梦（DM）。约 18k 行代码，129 个源文件。

**实际实现**

- 权限：permissions/roles/user_roles/role_permissions 四表 RBAC，14 个权限点（page_* / project_* / user_* / role_manage），前端 `usePermissions` hook。
- AI：可配置多模型（model_configs 表，默认 minimax-cn / MiniMax-M2.5），支持自然语言创建任务、任务分析、悬浮聊天（floating-chat.tsx）。

## 环境/工具坑（Docker 起不来排查）
用户机器装了 VMware，Docker Desktop 报 "Virtualization support not detected"。根因通常是：为让旧版 VMware 跑而关掉了 Hyper-V / Virtual Machine Platform，连带 Docker 的 WSL2 后端失虚拟化。修复=启用 VirtualMachinePlatform+WSL+HypervisorPlatform 并把 `bcdedit /set hypervisorlaunchtype auto`，重启。VMware ≥15.5.5 可与 Hyper-V 共存。
- 教训：给用户在 Windows 上用的 **.bat 必须纯 ASCII + CRLF**，带中文 UTF-8 会被 GBK 代码页 cmd.exe 解析乱码（`dism` 被拆成多段"不是内部命令"，自我提权路径引号报"语法不正确"）。
- 当前 agent 会话是**非管理员**沙箱：`bcdedit`/`wsl`/`reg`/`sc` 等系统级工具被禁，PowerShell 输出不回显，无法远程改用户机器的启动配置；此类系统级修复须用户在自己的管理员终端执行。已生成修正版脚本 `.workbuddy/enable-docker-virtualization.bat`。
